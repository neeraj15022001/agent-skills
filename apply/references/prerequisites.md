# Inputs and Inline Setup

Read `references/data-directory.md` relative to this skill folder. Reuse relevant supplied material and session answers before asking for anything.

| Workflow | Required | Optional |
|---|---|---|
| job-search | Resume/background and target-role/location preferences | Salary constraints, profile, contacts |
| network-scan | Resume/background, preferences, contacts CSV | Profile, existing cache |
| tailor-resume | Resume and target posting URL or text | Work history profile |
| cover-letter | Resume and target posting URL or text | Profile, tailored resume |
| apply | Resume, target application, answers to required fields | Profile, saved answers, existing drafts |

If required information is absent, ask one focused question for the missing inputs and continue independent work. A missing profile is not blocking: use supported resume facts, omit unverified claims, and note material gaps. Do not invent assumptions and then require the user to approve them.

For a first search, collect target roles and location/remote constraints together. Ask about salary only when needed to filter; never assume currency or US geography. For a network scan, request an existing contacts-export path or attachment if none is supplied. Do not require a plugin setup command.

Create missing preferences/profile files from actual answers as needed. Template examples are not candidate facts. Initialize empty history only when saving results. An absent browser does not block resume or letter drafting from supplied posting text.
