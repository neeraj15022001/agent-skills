# Cover Letter

Read `references/priority-hierarchy.md`, `references/data-directory.md`, and `references/prerequisites.md`.

1. Resolve the target from the user's supplied URL/text or current job context. For an explicit `last` request, use the latest saved posting and state the selected role. Ask when the target is missing or ambiguous. Reuse saved materials only when the posting URL/ID matches, not merely the company name.
2. Fetch a URL with `references/browser-setup.md` when needed; drafting from supplied posting text needs no browser. Load the original resume, optional profile, and a tailored resume for this exact job if available. Save the posting with provenance in its per-job folder.
3. Follow `scripts/write-cover-letter.md` locally as a writing reference. Connect two or three supported achievements to the employer's stated needs. Preserve employer attribution, dates, employment status, and scope. A profile or tailored resume is helpful but not required. Do not invent metrics or employer challenges.
4. Default to a concise 250–350-word letter, with a known recipient's name when supplied or 'Dear Hiring Manager' otherwise. Follow the user's length, tone, and formatting requests. Review line by line for factual accuracy, chronology, clear language, and natural flow.
5. Save `cover-letter.md` in the exact job's folder. Present the letter and an absolute file link with a brief explanation of selected evidence. Use an available document skill for requested PDF/DOCX export and inspect its output. Apply requested edits; do not send or submit the letter unless that external action is authorized.
