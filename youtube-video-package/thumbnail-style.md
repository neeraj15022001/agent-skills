# Channel thumbnail art direction

Use as the default for this user's technology videos. Explicit user directions and newer supplied channel references take priority.

## Visual identity

- Dark navy and indigo background with broad flowing wallpaper curves and fine lavender luminous edges.
- Huge clean heavy white sans-serif headline, subtle cool edge glow or shadow, strong mobile-size contrast.
- Small product label above headline. Optional short supporting line below, with generous letter spacing.
- Roughly 40–45% of frame for headline at left; roughly 55–60% for hero hardware at right. Adjust to avoid collisions.
- Photoreal silver MacBook or topic-appropriate device, purple rim lighting, controlled reflections on a dark surface, premium technology editorial finish.
- One instantly readable visual metaphor based on the actual feature: aperture on a flat screen for sleep animation; monitor and brightness slider for display dimming; document for resume creation.
- Supporting peripherals only when the transcript covers them. One dominant subject, minimal clutter.
- Generous outer safe margins; keep important text and details away from the bottom-right duration overlay.
- No people by default. No fake awards, scores, performance metrics, gratuitous arrows, A/B testing elements, or screenshot-like platform chrome.

## Production prompt template

Create one finished YouTube thumbnail, landscape 16:9, for [PRODUCT/TOPIC].

Source-grounded premise: [VIEWER PROBLEM + DEMONSTRATED SOLUTION].

Reference roles: [IMAGE] is a style/composition reference only. Preserve its [PALETTE, TYPOGRAPHY, LIGHTING], replacing its old subject, branding, and words. [SCREENSHOT, IF AVAILABLE] is an interface reference; preserve its relevant details without inventing features.

Exact text:
- Product label: "[PRODUCT]"
- Main headline: "[SHORT HOOK]"
- Optional supporting line: "[SUPPORTED FEATURE PHRASE]"

Composition: massive clean white headline on left, [TOPIC-APPROPRIATE HERO] on right, balanced clear spacing. Navy/indigo flowing background, fine lavender curved edges, silver materials, purple rim lighting, soft dark-surface reflection. [CONCRETE MAIN VISUAL EFFECT].

If no app screenshot was supplied: use a clearly stylized conceptual screen with simple icons, not a purported exact app screenshot. Do not invent official branding.

Constraints: exact spelling, no additional slogans or irrelevant logos, no people unless requested, no A/B testing, no unsupported claims. Keep text readable at small size and inside generous margins. Keep bottom-right timestamp area clear of essential content.

## Inspection

Inspect generated output before delivery. Verify exact headline spelling, no leftovers from reference, feature representation, and small-size readability. Inspect dimensions and format. For edits, preserve unrelated elements and save a new version. Reference asset is an example of visual style, not proof of any app's actual interface or branding.
